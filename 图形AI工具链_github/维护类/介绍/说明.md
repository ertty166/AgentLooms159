# AI工具链可视化编排平台

基于 PySide6 的节点编辑器，支持插件系统和多进程执行。

## 目录结构

```
平台/
├── 入口.py          # 程序入口
├── 核心_插件引擎.py  # 插件管理+进程控制
├── 核心_基础.py      # 配置、信号、状态
├── 核心_日志.py      # 日志系统
├── 界面_画布.py      # 节点、连线、端口
├── 界面_主窗.py      # 主窗口
├── tools.py         # 自定义的工具包,主要用于自动路径遍历查找
|
├── 维护类/            # 核心模块
|   └── 依赖.txt         # 依赖列表
│   
├── 插件/            # 内置插件
│   ├── 测试.py
│   ├── 回显.py
│   └── 数学.py
└── 示例/            # 示例流程
    └── 简单流程.json
```

## 启动

```bash
pip install -r 依赖.txt
python 入口.py
```

## 插件开发

```python
"""
插件描述
"""

__名称__ = "我的插件"
__版本__ = "1.0.0"
__作者__ = "作者"
__分类__ = "通用"

def 处理(数据):
    """处理数据"""
    发送日志("信息", f"收到: {数据}")
    return str(数据).upper()

发送日志("信息", "插件已加载")
```
