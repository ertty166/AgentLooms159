### 1. 插件加载逻辑
- **核心文件**：核心_插件引擎.py
- **关键类/方法**：
  - `插件管理器`类：负责插件加载、解析、刷新
  - `加载插件()`：读取插件文件（内置/用户目录），调用`_解析信息()`校验插件合法性
  - `_解析信息()`：通过AST解析插件代码，提取元数据（名称/版本等），检查是否含`处理`函数（插件核心逻辑入口）
  - `刷新()`：清空现有插件，遍历`插件`目录加载所有.py插件文件
- **触发时机**：主窗口初始化时调用`插件.刷新()`（界面_主窗.py）

### 2. 进程创建逻辑
- **核心文件**：核心_插件引擎.py
- **关键类/方法**：
  - `进程管理器`类：管理插件进程生命周期
  - `创建进程()`：为指定节点ID创建`插件工作线程`，启动线程后创建子进程
  - `插件工作线程`类：封装multiprocessing.Process，`run()`方法中启动子进程，`_运行插件()`为子进程执行入口
  - 子进程创建：通过`mp.Process`启动，绑定输入/输出队列，执行插件的`处理`函数
- **进程特性**：子进程为守护进程，通过队列与主线程通信，支持优雅停止/强制终止

### 3. 插件通讯逻辑
- **通信方式**：基于multiprocessing.Queue（输入队列/输出队列）
- **核心交互**：
  - 主线程→子进程：`发送数据()`向输入队列写入{"数据": 内容}，子进程循环读取队列执行`处理`函数
  - 子进程→主线程：子进程通过`发送输出/发送日志/发送状态`向输出队列写数据，主线程轮询队列解析并触发对应信号
  - 控制指令：向输入队列写入{"命令": "停止"}触发插件进程退出
- **信号关联**：进程管理器将队列消息转为Qt信号（进程启动/结束/输出/错误），关联至全局信号

### 4. 端口与插件进程的关联
- **端口核心文件**：界面_画布.py（端口类、连线类）
- **关联逻辑**：
  1. 端口是画布上节点的输入/输出组件，仅负责数据流转的可视化连接，不直接绑定进程
  2. 节点ID为核心关联标识：
     - 每个插件进程绑定唯一节点ID（`创建进程(节点ID, 代码)`）
     - 端口所属节点的ID与插件进程的节点ID一致
     - 连线的起点/终点端口关联不同节点ID，流程执行时按连线关系，将上游节点进程的输出数据通过`发送数据()`写入下游节点进程的输入队列
  3. 端口无独立句柄，插件句柄问题大概率指向：
     - 进程创建失败（队列初始化/子进程启动异常）
     - 队列读写超时/句柄未释放（进程停止时队列未正确关闭）
     - 节点ID重复导致进程冲突，或端口连线后数据流转时进程未正确接收/发送数据

### 5. 具体方法关联
# 1. 插件加载逻辑
文件：核心_插件引擎.py
核心类：插件管理器
核心方法：
加载插件()：读取插件文件并完成加载
_解析信息()：解析插件元数据、校验处理函数
刷新()：遍历目录批量加载插件
# 2. 进程创建逻辑
文件：核心_插件引擎.py
核心类：进程管理器、插件工作线程
核心方法：
创建进程()：为节点创建并启动工作线程
插件工作线程.run()：初始化队列、创建子进程
插件工作线程._运行插件()：子进程执行插件逻辑
停止进程()：停止指定节点的进程与线程
# 3. 插件通讯逻辑
文件：核心_插件引擎.py
核心类：插件工作线程、进程管理器
核心方法：
插件工作线程.发送数据()：主线程向子进程发送数据
插件工作线程.run()：轮询队列接收子进程返回信息
插件工作线程._运行插件()：子进程接收指令、执行处理函数并回传结果
进程管理器.发送数据()：统一转发数据到目标插件进程
# 4. 端口与插件进程关联
文件：界面_画布.py、核心_插件引擎.py
核心类：端口类、连线类、进程管理器
核心方法：
端口/连线类：通过节点ID建立数据连接关系
进程管理器.发送数据()：依据节点ID（端口所属节点）将数据发送到对应插件进程
节点ID作为唯一标识，绑定端口、连线、插件进程三者关系


### 插件句柄问题排查重点
1. 检查`插件工作线程`中队列初始化（`mp.Queue`）是否失败，或队列句柄未释放
2. 验证`停止进程()`中是否正确执行`进程.terminate()`/`kill()`，避免僵尸进程占用句柄
3. 核对节点ID唯一性，确保同一节点未重复创建进程
4. 检查端口连线后，上游进程输出是否正确传递至下游进程输入队列（句柄无效可能是队列读写异常）
